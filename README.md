## Маппинги

### Neovim
* :ls           - показать список открытых буферов
* :b 3          - перейти к буферу 3

### nvim-cmp plugin
* \<C-n\>       - Выбрать следующий пункт в меню
* \<C-p\>	    - Выбрать предыдущий пункт в меню
* \<C-b\>	    - Прокрутить окно документации вверх
* \<C-f\>	    - Прокрутить окно документации вниз
* \<C-Space\>   - Открыть меню автодополнения вручную
*\<C-e\>	    - Закрыть меню без выбора
* \<CR\> 	    - Подтвердить выбранный пункт
* \<Tab\>	    - Следующий пункт / переход по сниппету / обычный Tab
* \<S-Tab\>	    - Предыдущий пункт / переход назад по сниппету / обычный Shift-Tab,

### В config/mappings.lua

\<leader\> = ' '

#### переключение между окнами
* \<leader\>h   - влево
* \<leader\>j   - вниз
* \<leader\>k   - вверх
* \<leader\>l   - вправо

* \<leader\>ds  - замена двойных $$ на $

* \<leader\>m   - переход к маппингам
